# AI Image Classification (MNIST) - VS Code

A deep learning project that trains a Convolutional Neural Network (CNN) 
to recognize and classify handwritten digits (0–9) with ~99% accuracy 
using the MNIST dataset.

Built with Python, TensorFlow/Keras — runs directly in VS Code.

✨ Features:
- Trained on 60,000 handwritten digit images
- ~99% accuracy on test data
- Real-time training metrics (loss & accuracy per epoch)
- Confusion matrix + classification report
- Predict custom digit images
- Clean modular code structure

🛠️ Tech Stack:
Python | TensorFlow | Keras | NumPy | Matplotlib | MNIST

🚀 Run it:
pip install -r requirements.txt
python src/main.py
